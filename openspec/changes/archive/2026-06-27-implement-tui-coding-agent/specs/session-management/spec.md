## ADDED Requirements

### Requirement: 多轮对话上下文维护

系统 必须 (MUST) 维护完整的多轮对话上下文，包含用户消息、助手回复、工具调用请求、工具执行结果、权限决策结果和错误信息。所有交互信息按时间顺序累积在会话历史中。

#### Scenario: 消息按序累积
- **给定** 用户依次发送 3 条消息
- **当** 每条消息处理后
- **那么** 系统 必须 (MUST) 按时间顺序累积所有用户消息、助手回复、工具调用和工具结果

#### Scenario: 上下文用于后续推理
- **给定** 第 1 轮对话中 Agent 读取了 `main.py` 的内容
- **当** 第 2 轮对话中用户询问相关问题时
- **那么** 系统 必须 (MUST) 在上下文中包含第 1 轮的 `read_file` 结果

#### Scenario: 错误信息进入上下文
- **给定** Agent 执行工具时发生错误（如文件不存在、命令执行失败）
- **当** 错误发生后
- **那么** 系统 必须 (MUST) 将错误信息作为工具结果注入会话上下文，使 LLM 能够感知错误并调整后续行为

### Requirement: 会话日志持久化

系统 必须 (MUST) 在每次 Agent 交互完成后，将完整会话历史以 JSONL 格式持久化到 `.tui-agent/logs/{session_id}.jsonl`。每条记录包含 type、content、timestamp 字段。

#### Scenario: 对话结束后自动保存
- **给定** 用户完成一轮对话
- **当** Agent Loop 结束
- **那么** 系统 必须 (MUST) 将完整会话历史写入 `.tui-agent/logs/` 目录下的 JSONL 文件

#### Scenario: JSONL 格式正确性
- **给定** 会话包含用户消息、工具调用和助手回复
- **当** 持久化到 JSONL 文件
- **那么** 系统 必须 (MUST) 每行写入一条合法的 JSON 记录，包含 type、content、timestamp 字段

### Requirement: 会话清空

系统 必须 (MUST) 支持通过 `/clear` 命令清空当前会话上下文，开始新的会话。清空操作不影响已持久化的日志文件。

#### Scenario: 清空当前会话
- **给定** 当前会话包含 5 轮对话
- **当** 用户输入 `/clear`
- **那么** 系统 必须 (MUST) 清空内存中的会话历史，TUI 界面重置为空，但不删除 `.tui-agent/logs/` 中的历史日志
