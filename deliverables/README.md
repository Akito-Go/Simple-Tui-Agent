# 验证产物说明

本目录存放使用 TUI Agent 完成小任务后的可运行代码与关键截图，用于证明 Agent 在真实环境中可用。

## 可运行代码

| 文件 | 说明 | 运行方式 |
|------|------|----------|
| `tetris.py` | 俄罗斯方块（Pygame，含中文字体自动检测） | `python3 deliverables/tetris.py` |
| `snake.py` | 贪吃蛇小游戏 | `python3 deliverables/snake.py` |

> 需在项目根目录执行，并已安装 `pygame`（`pip install pygame`）。

## 验证任务对应关系

- **演示目标**：用 Coding Agent 完成一个小任务（如小游戏）并附运行截图
- **实际完成**：俄罗斯方块 + 贪吃蛇两个小游戏，含实现过程与运行效果截图
- **测试截图**：`测试用例通过.png` 等对应 `pytest tests/` 全绿状态
